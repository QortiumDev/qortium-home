# Test fixtures

`core-qdn-attestation.json` is generated by Qortium Core's real public ZIP
builder. It captures the unsigned transaction, approved source ZIP, encrypted
staged artifact, and signed metadata artifact used by Home's cross-runtime QDN
content-attestation test.

The checked-in fixture was generated from Qortium Core 1.5.0 commit
`e2a417881` (`ArbitraryApiTests#testPublicStagedDataEndpointReturnsExactContentAddressedArtifacts`).

Regenerate it from the sibling `qortium-core` checkout with:

```sh
mvn -q -DskipTests=false \
  -Dtest=ArbitraryApiTests#testPublicStagedDataEndpointReturnsExactContentAddressedArtifacts \
  -Dqortium.publicQdnAttestationFixture=/tmp/qortium-core-qdn-attestation-fixture.json \
  test
```

Then replace this repository's fixture with the generated JSON and run
`npm run test:qdn-content-attestation`. AES-GCM randomness and the transaction
timestamp make the captured bytes change between regenerations; acceptance is
based on Core's cryptographic and transaction-format invariants, not fixed
hash literals.
